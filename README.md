# Hedera Token Mint on Tangem

A privacy-respecting iOS / Android app for minting **Hedera Token Service (HTS)** tokens, signed by a **Tangem hardware wallet** over NFC. Built with React Native + Expo and the official `tangem-sdk-react-native`.

The treasury private key never leaves the Tangem chip. The operator (HBAR-paying) key is entered at runtime and held only in memory.

## Capabilities

- Mint fungible tokens or NFTs with one Tangem tap
- Per-token control over all eight HTS keys (`admin`, `supply`, `kyc`, `wipe`, `freeze`, `feeSchedule`, `pause`, `metadata`)
- Custom fees: fractional %, fixed HBAR, fixed token, NFT royalty + fallback
- Infinite or finite supply caps
- Optional auto-association flow when the fee collector is a separate account
- Hedera SLIP-0010 derivation (`m/44'/3030'/0'/0'/0'`)

## Status

Early. The mint flow works on Hedera mainnet and testnet. Roadmap items (mint/burn/transfer ops, multi-account support, NFT metadata uploads) are listed at the bottom.

## Requirements

- macOS with Xcode 16+ (developer mode enabled)
- iPhone with NFC (iPhone 7 or newer) **or** an Android device with NFC
- Apple Developer Program membership ($99/yr) for iOS — Apple's free Personal Team does **not** allow the NFC reader entitlement
- A Tangem card with at least one Ed25519 SLIP-0010 wallet
- A Hedera mainnet (or testnet) account with HBAR for fees
- Node.js 20+

## Setup

```bash
git clone https://github.com/<owner>/hedera-token-mint-on-tangem.git
cd hedera-token-mint-on-tangem
npm install
```

Edit `src/config.ts`:

| Field | What to put there |
|---|---|
| `OPERATOR_ACCOUNT_ID` | Your Hedera account that pays HBAR fees |
| `TREASURY_ACCOUNT_ID` | Account that receives initial supply, controlled by your Tangem |
| `FEE_COLLECTOR_ACCOUNT_ID` | Optional. Leave empty to route fees to the treasury |
| `TANGEM_KEYS.treasury` | Ed25519 hex pubkey derived on the treasury Tangem card |
| `TANGEM_KEYS.feeCollector` | Same, for the fee-collector card. Duplicate the treasury key if you don't use a separate collector |

The placeholder values (`0.0.0`, sixty-four zeros) are intentionally invalid; the app refuses to mint until they are replaced.

### iOS

```bash
npx expo prebuild --platform ios --clean
cd ios && LANG=en_US.UTF-8 pod install && cd ..
bash scripts/patch-tangem-nfc.sh   # see "Tangem NFC patch" below
open ios/*.xcworkspace
```

In Xcode:

- **Signing & Capabilities**: pick your Apple Developer team
- **Bundle Identifier**: change `app.hederatokenmint` to your own reverse-DNS string
- Confirm "Near Field Communication Tag Reading" capability is present

Then build to your iPhone over USB and start Metro:

```bash
npx expo start --dev-client
```

### Android

```bash
npx expo prebuild --platform android --clean
npm run android
```

Android does not require a paid developer program; sideloading via `adb` is enough.

## Usage

1. Open the app — it connects to Metro for the JS bundle.
2. **Step 1 — Setup.** Enter your operator private key and tap your treasury Tangem card.
3. **Step 2 — Token specification.** Pick fungible/NFT, enter name/symbol/supply, optionally add a custom fee, choose which token keys you want enabled.
4. **Step 3 — Open auto-association** (only shown when you configure a custom fee with a separate collector). Tap the fee-collector card to sign an `AccountUpdate` that opens an auto-association slot.
5. **Step 4 — Mint.** Tap the treasury card to sign the `TokenCreate`. The new token ID is shown with a HashScan link.

## Security

- The Tangem chip physically holds the treasury / fee-collector private keys. The app cannot extract them.
- The operator private key lives only in memory until the app closes. It is never persisted.
- Public keys appear on-chain by Hedera's design — that is normal blockchain behaviour, not a leak.
- This is alpha software. Audit the transaction-builder code in `src/hedera.ts` against your own threat model before deploying real value.

## Architecture

```
App.tsx                  # screen flow + form state
src/config.ts            # USER-EDITABLE: accounts, derivation, network
src/hedera.ts            # @hashgraph/sdk transaction builders
src/tangem.ts            # tangem-sdk-react-native wrapper, role-based scan + sign
src/theme.ts             # design tokens (colors, type, spacing)
src/components/          # reusable UI primitives
ios/, android/           # generated by `expo prebuild`
```

### Tangem NFC patch

The Tangem SDK 3.1.0 only enables its "reduce restart polling" path on a hardcoded list of "broken" devices, but iOS 17 / 18 / 26 hit the same NFC regression on every device we've tested. Without the patch you'll see `Incomplete process. To finalize the operation, kindly tap the card again` in the middle of multi-step flows.

`scripts/patch-tangem-nfc.sh` rewrites the gate to always trigger on iOS 17+. It's idempotent — run it again after every `pod install` until upstream merges a fix.
